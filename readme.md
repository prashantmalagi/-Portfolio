# 🌐 Prashanth Malagi - Portfolio

A modern, responsive, and interactive developer portfolio showcasing my projects, skills, experience, and achievements. Built with a futuristic UI, smooth animations, and a focus on creating a premium user experience.

## 🚀 Live Demo

🔗 **Portfolio:** https://prashanthmalagi.vercel.app

## 📌 Features

- 🎨 Modern Dark UI with Glassmorphism
- ✨ Smooth GSAP Animations
- 📱 Fully Responsive Design
- 💻 Interactive Project Showcase
- 🛠️ Skills Section with Progress Indicators
- 📈 GitHub Activity Integration
- 🏆 Achievements Timeline
- 📧 Contact Form
- 🌙 Premium User Experience
- ⚡ Fast Performance & Optimized Assets

## 📸 Screenshots

Create a folder named **screenshots** and add your portfolio screenshots.

Example:

```text
screenshots/
│── hero.png
│── about.png
│── projects.png
│── contact.png
```

Then include them like:

```md
### Hero

![Hero](screenshots/hero.png)

### Projects

![Projects](screenshots/projects.png)
```

## 🚀 Run Locally

Clone the repository

```bash
git clone https://github.com/prashantmalagi/portfolio.git
```

Go to the project folder

```bash
cd portfolio
```

Open `index.html`

or run with VS Code Live Server.
